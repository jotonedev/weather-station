# Shared libraries

## AHT20

- Temperature and humidity sensor
- I2C

## BMP280

- Pressure sensor
- I2C

## Neo 6

- GPS sensor
- UART communication

## CC1101

- Wireless module for 433 MHz transmissions
- SPI communication

## PMS7003

- Particle concentration sensor
- UART communication
- Requires 5v power but uses 3.3v UART

## SGP30

- Air quality sensor
- I2C
