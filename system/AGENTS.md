# Rules

## Testing

- Use clear, descriptive variable names (e.g. `readings`, `wantStored`), avoid single-letter variables.

## Comments

- Doc comments are full sentences that begin with the name of the thing they describe and end with a period.
- Keep comments concise, a single line wherever possible. Expand only when necessary.
- Prefer explaining "why" over "what". Do not restate what the code already shows.

## Notes

- No need to regenerate protobuf files each time, there is an automated workflow for it
