1. Weather Station platform has been successfully deployed.

2. Access the Web Frontend:
{{- if .Values.ingress.enabled }}
  Host: http://{{ .Values.ingress.host }}
  Ingress Controller: {{ .Values.ingress.className | default "traefik" }}
  - Web UI: http://{{ .Values.ingress.host }}/
  - Ingestion endpoint: http://{{ .Values.ingress.host }}/reading
{{- else }}
  Forward frontend port to localhost:
  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "weather-station.fullname" . }}-frontend 8080:8080
  Open http://localhost:8080 in your browser.
{{- end }}

3. Embedded Database Status:
  DuckDB runs embedded directly inside the database microservice with persistent storage.
  Check database logs:
  kubectl logs -n {{ .Release.Namespace }} deployment/{{ include "weather-station.fullname" . }}-database

4. Service Pod Status:
  Check service pod status:
  kubectl get pods -n {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "weather-station.name" . }}"
