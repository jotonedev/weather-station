1. Weather Station platform has been successfully deployed.

2. Access the Web Frontend:
{{- if .Values.ingress.enabled }}
  Host: http://{{ .Values.ingress.host }}
  Ingress Controller: {{ .Values.ingress.className | default "traefik" }}
  - Web UI: http://{{ .Values.ingress.host }}/
  - Ingestion endpoint: http://{{ .Values.ingress.host }}/reading
{{- else }}
  Forward frontend port to localhost:
  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "weather-station.fullname" . }}-frontend 8080:8080
  Open http://localhost:8080 in your browser.
{{- end }}

3. Database Seeding Status:
  Check the initialization logs of the database pod:
  kubectl logs -n {{ .Release.Namespace }} deployment/{{ include "weather-station.fullname" . }}-database -c db-seed

4. QuestDB Web Console:
  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "weather-station.fullname" . }}-questdb 9000:9000
  Open http://localhost:9000 in your browser.

5. gRPC Probes & Service Mesh Status:
{{- if .Values.istio.enabled }}
  - Istio strict mTLS is enabled.
  - Telemetry configured with Jaeger provider.
{{- end }}
  Check service pod status:
  kubectl get pods -n {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "weather-station.name" . }}"
